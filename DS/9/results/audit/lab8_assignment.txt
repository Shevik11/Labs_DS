Лабораторнаробота№8Збереженнязнаньуграфбазі даних
Опис:Уцій лабораторній роботі використовуєтьсяграфовабазаданих(наприклад, Neo4j) длязберіганнязнаньзонтології, побудованої напопередніхетапах. Роботапередбачаєімпортзнанньвбазу, структуруванняїхувигляді графа, атакожвиконанняоптимізованихзапитівдляотриманняпотрібної інформації.
Метароботи:1. Навчитисявикористовуватиграфовубазуданихдлязбереженнязнань.2. Розробитизапитидобазизметоюшвидкоготаефективногодоступудоінформації.
Інструменти:● Neo4j
Порядоквиконання:1. Оглядграфбазданих● ОзнайомленнязNeo4j:○ ПрочитайтедокументаціющодовикористанняNeo4j якграфової базиданих.○ Встановіть Neo4j на локальній машині або використовуйте Neo4j Sandbox для онлайнроботи.● ПідключеннядоNeo4j:○ Підключіться до Neo4j через браузерний інтерфейс або встановіть Neo4j Desktop длялокальної роботи.○ Переконайтеся, щосерверNeo4j запущенийі виможетевзаємодіятизбазою.
2. Структуруванняданих● Перетворенняонтології уграфовуструктуру:○ Визначте ключові поняття та їх зв'язки з побудованої онтології (наприклад, "Курс","Студент", "Тема").○ Структуруйте дані у формат, що підтримується граф базами даних, де кожен вузолвідповідає окремому поняттю, а ребра — це взаємозв'язки між ними (наприклад,"СтудентпроходитьКурс").● Підготовкаданихдоімпорту:○ ВикористайтемовуCypher дляописувузлівтазв'язківміжними.○ ПідготуйтеCSVабоJSONфайли, які містятьвузлиі зв'язкидляімпортувNeo4j.

Приклад:
CREATE (s:Student {name: "John Doe"})CREATE (c:Course {name: "Introduction to AI"})CREATE (s)-[:ENROLLED_IN]->(c)
3. Збереженнязнаньуграфбазі даних● ІмпортданихчерезCypherабоAPI:○ Використайте Cypher для створення вузлів (понять) та встановлення зв'язків міжними.Якщо ви використовуєте API (наприклад, Python з бібліотекоюpy2neo), створіть скриптдляавтоматизованогоімпорту.● Перевіркаданих:○ Перевірте правильність імпортованих даних через інтерфейс Neo4j. Візуалізуйте граф іпереконайтеся, щовсі вузлиі зв'язкивідображені коректно.ПрикладімпортучерезCypher:
LOAD CSV WITH HEADERS FROM 'file:///students.csv' AS rowCREATE (:Student {name: row.name, age: toInteger(row.age)});
4. Оптимізаціязапитівдобази● Написаннязапитівдляотриманнязнань:○ Напишіть кілька базових запитів, щоб витягнути інформацію з бази. Наприклад, запитпроте, які курсипроходитьконкретнийстудент.
MATCH (s:Student)-[:ENROLLED_IN]->(c:Course)WHERE s.name = "John Doe"RETURN c.name
● Оптимізаціязапитів:○ Використовуйте індекси дляприскоренняпошукуданих. Наприклад, створітьіндексидляіменстудентівабоназвкурсів.
CREATE INDEX ON :Student(name);
5. Тестування продуктивності: Виконайте кілька складних запитів і виміряйте їх продуктивність(часвиконання, обсягданих).
